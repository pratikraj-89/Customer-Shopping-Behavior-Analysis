# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview

The **Customer Shopping Behavior Analysis** project focuses on analyzing customer purchasing patterns, shopping preferences, revenue performance, product popularity, and subscription behavior using Python, SQL, and Microsoft Power BI.

The project follows an end-to-end data analytics workflow, starting from data cleaning and preprocessing in Python, performing business-oriented analysis using SQL, and finally building an interactive dashboard in Power BI to present meaningful insights.

The primary objective is to transform raw customer shopping data into actionable business insights that can help businesses understand customer behavior and make data-driven decisions.

---

## 🎯 Project Objectives

- Analyze customer purchasing behavior and shopping patterns.
- Understand revenue distribution across different customer segments.
- Identify popular products and product categories.
- Analyze the impact of discounts on customer spending.
- Compare purchasing behavior of subscribers and non-subscribers.
- Evaluate customer preferences based on shipping methods.
- Segment customers based on their previous purchasing history.
- Build an interactive Power BI dashboard to visualize key business metrics.

## 🐍 Python – Data Cleaning & Preprocessing

Python and Pandas were used to prepare the raw dataset for further analysis.

### Tasks Performed

- Imported the dataset using Pandas.
- Explored dataset structure using `head()`, `info()`, and `describe()`.
- Checked missing values using `isnull().sum()`.
- Handled 37 missing values in the `Review Rating` column using category-wise median imputation.
- Standardized column names by converting them into lowercase and replacing spaces with underscores.
- Renamed `purchase_amount_(usd)` to `purchase_amount`.
- Created customer age groups using `pd.qcut()`:
  - Young Adult
  - Adult
  - Middle Aged
  - Senior
- Created a new `purchase_frequency_days` column by mapping purchasing frequencies into numerical day intervals.
- Removed the `promo_code_used` column after examining its relationship with `discount_applied`.
- Loaded the cleaned dataset into MySQL using SQLAlchemy and PyMySQL.

## 🗄️ MySQL – Business Data Analysis

After cleaning and preprocessing, the data was loaded into a MySQL database named `customer_behaviour`, inside a table named `customer`.

SQL was used to perform business-oriented analysis and extract meaningful insights.

### Business Questions & SQL Analysis

**1. Revenue Analysis**
- Compared total revenue generated by male and female customers.

**2. Discount and Spending Analysis**
- Identified customers who applied discounts and made purchases equal to or above the overall average purchase amount.

**3. Product Rating Analysis**
- Identified the top 5 products based on average customer review ratings.

**4. Shipping Analysis**
- Compared average purchase amounts between Express and Standard shipping methods.

**5. Subscription Analysis**
- Compared total customers, average spending, and total revenue between subscribers and non-subscribers.

**6. Discount Dependency Analysis**
- Identified the top 5 products with the highest percentage of discount-applied purchases.

**7. Customer Segmentation**
- Classified customers into three segments based on previous purchases:
  - New Customers
  - Returning Customers
  - Loyal Customers

**8. Product Popularity Analysis**
- Identified the top 3 most purchased products within each product category using window functions.

**9. Repeat Buyer Analysis**
- Analyzed subscription status among customers with more than 5 previous purchases.

**10. Age Group Revenue Analysis**
- Compared total revenue generated across different customer age groups.

### SQL Concepts Used

- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate Functions: SUM(), AVG(), COUNT()
- CASE Statements
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- ROW_NUMBER()
- PARTITION BY
- ROUND()
- LIMIT

## ⚙️ How to Run This Project

### Step 1: Clone the Repository

```bash
git clone https://github.com/pratikraj-89/Customer-Shopping-Behavior-Analysis.git
```

### Step 2: Navigate to the Project Directory

```bash
cd Customer-Shopping-Behavior-Analysis
```

### Step 3: Install Required Python Libraries

```bash
pip install pandas sqlalchemy pymysql jupyter
```

### Step 4: Run the Python Notebook

Open the `CustomerShoppingBehaviour.ipynb` file using Jupyter Notebook or VS Code.

Run the notebook to perform data cleaning and preprocessing.

### Step 5: Configure MySQL Database

- Make sure MySQL Server is running.
- Create or use the `customer_behaviour` database.
- Configure your MySQL connection credentials securely in the Python notebook.
- Execute the notebook to load the cleaned dataset into the `customer` table.

### Step 6: Execute SQL Queries

Open `Customer_Behaviour_Analysis.sql` in MySQL Workbench and execute the analysis queries after loading the cleaned dataset.

### Step 7: Open Power BI Dashboard

Open `Customer_Shopping_Behaviour_Dashboard.pbix` using Microsoft Power BI Desktop.

Configure the MySQL connection if required.
